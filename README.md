# Smart Legal Case Management System (SLCMS)

Enterprise Smart Legal Case Management System designed for modern law firms to streamline litigation, clients, privileged documents, statutory deadlines, AI legal research, and billing.

## 🚀 Key Features

- **Case Management & Tracking**: End-to-end litigation workflows, stage tracking, hearings, and evidence registers.
- **Client & Conflict Management**: Complete client lifecycle management with automated conflict-of-interest checks.
- **AI Legal Assistant & Tanzanian Legal Research**: Semantic search, statutory query routing, document indexing, and AI assistance.
- **Document Management**: Secure document vault, privilege classifications, OCR/PDF text extraction, and version control.
- **Statutory Deadlines & Task Orchestration**: Limitation dates, court hearing alerts, and priority task queues.
- **Time Tracking & Billing**: Hourly tracking, retainer management, automated fee notes, and billing analytics.
- **Analytics & Reporting**: Interactive visual dashboards and management reporting.

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (SPA architecture), Modern CSS3 with Design System Tokens, Chart.js.
- **Backend**: Java 17+, Spring Boot, Apache PDFBox, RESTful APIs.
- **AI & Document Indexing**: Semantic legal search and passage extraction engine.

## 💻 Getting Started

### Frontend
Open `index.html` directly in a modern web browser or serve it with any static web server:
```powershell
.\server.ps1
```

### Backend
Navigate to the `backend` folder and run with Maven:
```bash
cd backend
mvn spring-boot:run
```
